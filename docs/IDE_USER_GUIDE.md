# IDE 使用指南 — 輸入框 → core 引擎 → 輸出框 (v0.2.1)

## 你本地已驗證：cargo build 成功生成 target/release

```bash
cargo build --release -p polyrust-core --bin polyrust
# -> target/release/polyrust 2.5M

cargo build --release -p polyrust-ide --features light
# -> target/release/polyrust-ide
```

`target/` 與 `core/src/` 完全分離，編譯唔會破壞源碼。

## 舊版問題：只有介面用唔到

舊版 `frontends/ide/src/main.rs` 只係 fallback：

```rust
rust_code = Some(format!("// Fallback generation ... {}", json_str))
```

無真正調用 `pipeline_v3` 的 `generated_rust`，所以輸出框空。

## 新版已修復：core 引擎已接入管線

`frontends/ide/src/main.rs` v0.2.1 新版：

```rust
let result = polyrust_core::pipeline_v3::run_pipeline_v3_with_config(&source_name, &content, None, &config);
match result {
    Ok(v3) => {
        rust_code = v3.generated_rust.clone(); // 真實 Rust
        qap_verified = v3.self_verification_passed.unwrap_or(false);
        risk_score = v3.commercial.risk_score;
        lean_refs = v3.commercial.lean_proof_refs;
        audit_md = Some(...);
    }
}
```

## 後續開發：喺 IDE 上開發把 core 引擎接入管線

已經完成，架構：

```
[瀏覽器]
  輸入框 (textarea#code) ──┐
                          │ POST /api/ide/compile {path, content, mode}
                          ▼
[axum IDE 後端] ──→ polyrust_core::pipeline_v3::run_pipeline_v3_with_config
                    CDCL × Buchberger(F4/F5) × QAP
                    ↓
                    generated_rust, poly_code, audit_md, risk, lean_refs, safety_gates
                          │
                          ▼
  輸出框 (textarea#rust-output) + 診斷/審計/Poly/Lean 分頁
```

**人類輸入 → 管線 → core 引擎運算 → 輸出框** 已打通。

```bash
cargo build --release
./target/release/polyrust-ide 8080
# 瀏覽器打開 http://localhost:8080
# 輸入 → 編譯 → 輸出
```

target/release/ 在 target/ 內，源碼在 core/src/，互不干擾，多工具 cargo check/test/deny/tree + lean + polyrust 協同。
